# Phase 0.2: provider terms audit

Audit date: 2026-11-14. Scope: free tiers, limits, egress and acceptable-use terms for Freeweights Stage 0 hosting, plus credit programs.

Method and caveats:
- Pages were read with a web fetch tool that returns a summary. Text marked **[summary]** is the fetch tool's paraphrase of the page, not verified verbatim. Each one must be checked against the live page before anything is shipped on it.
- Text marked **[search]** comes from a search-result snippet, not from the page itself.
- "blocked" = the server returned 403/404 to the fetch tool. "not found" = the page was read and the clause does not appear.
- No figure below is estimated. Where a number was derived (for example, a per-GB price), it is labelled as derived.

## Risks for Stage 0

- **R2 storage is the binding limit.** 10 GB total, Standard storage only. The model set in Phase 0.1 cannot fit. Stage 0 must cap bytes per model and say so.
- **The Cloudflare CDN clause (row 1h) may block serving large files on Free.** Resolve it with a human read and a written answer from Cloudflare before Stage 0 serves model files at all.
- **Oracle, Backblaze AUP and Wasabi AUP could not be cleared.** Oracle returned 403 on every relevant page. Backblaze AUP returned 404. Wasabi AUP has no text. Do not place public model files on any of them until the full text is read.
- **Hugging Face rate limits (5,000 resolver requests per 5 minutes for Free) and missing ToS clauses.** Absence in the ToS is not clearance. The Worker must cache and never resolve per request.
- **No credit programs are a dependable funding source.** Project Alexandria likely excludes for-profit projects. Fast Forward does not say. AWS favours foundation-owned projects. Plan Stage 0 without them.
