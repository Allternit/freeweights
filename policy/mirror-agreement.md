# Freeweights Mirror Host Agreement

Status: Draft. Owner: Allternit. Short form, counsel reviews before first use.

Between Allternit LLC ("Allternit") and the host named below ("Host").

Host: ______  Contact: ______  Region: ______  Capacity: ______

1. **What the mirror serves.** Files from the Freeweights list, over HTTP, with the same file names and bytes as the manifest. Host may choose which models and how much to hold.
2. **Sync.** Host syncs from the published sync spec. Files must match the sha256 in the signed manifest. A file that does not match is not served.
3. **License list only.** Host serves only models whose license is on the Freeweights list (license-allowlist.md). Allternit tells Host when a model is removed. Host removes it within 72 hours of notice. Host also removes content it is legally required to remove.
4. **Listing.** Allternit lists Host on /mirrors with name, logo, capacity, region and since-date. Host may ask to change or remove its listing. Listing does not change catalog order.
5. **No payment.** No money passes between the parties under this agreement. In-kind capacity is logged in the ledger at the value Host states, with consent.
6. **Logs and privacy.** Host handles its own server logs under its own law. Host does not add tracking or ads to served files.
7. **Ending.** Either side may end this agreement with 14 days' written notice, or at once if the other side breaks it. Host removes the Freeweights marks on ending. Allternit removes the listing.
8. **No warranty.** Files and services are provided as they are. Neither side gives a warranty. Neither side is liable for indirect loss.
9. **No exclusivity.** Each side is free to work with others.
10. **Law.** Minnesota law applies. [Counsel to confirm.]
