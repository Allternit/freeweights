# Freeweights Ethos

Status: Draft. Owner: Allternit. Wording approved by Allternit 2026-11-14 (plan v3, section B). Published at /ethos.

## Mission

Freeweights keeps open AI models open. Anyone can find, check and download them for free, with no account. Allternit, an American company, runs it in the open. The code is open source and the costs are public. Freeweights is subsidized: supporters, sponsors, mirror hosts and a share of Allternit's revenue pay for it.

## We always / We never

| We always | We never |
| --- | --- |
| Keep public models free to download. No paywall. No account. | List or host a model made for sexual content. Not now, not later. |
| Publish the license and a checksum with every file. | List or host child sexual abuse material, or a model built to make it. We remove it and report it. |
| Say where the bytes come from: hosted by Allternit, seeded by the community, or served from the source. | List or host a face or voice model of a real person without that person's documented consent. |
| Publish the code that runs Freeweights under an open license. | List or host a model marketed for fraud, malware or attacks. |
| Publish what Freeweights costs and who pays. | Sell ranking, placement or access. |
| Apply support money first to the running costs in the ledger, and show each dollar. | Show a model as available when it is not. |
| Welcome abliterated models. The card says what was changed. | Hide a takedown. Every removal is counted on a public page. |

## Wording notes

- "Apply first to the running costs" replaces "100% goes to hosting". Do not use the old phrase.
- "Of a real person" means one specific person. General speech models such as Kokoro stay allowed.
- "The code that runs Freeweights" means the hub, site, tools and specs. It does not mean the Allternit apps.
- Every support surface says: "Support goes to Allternit LLC. It is not a charitable gift and is not tax-deductible."
