If Hugging Face lists a model, Freeweights lists it. The license decides how: **Hosted (signed)**, with a signed manifest, when it allows copies with no acceptance gate and no territory limit; otherwise **From the publisher**, a link to the publisher's page with the reason. The table is a draft that counsel reviews.

## How a verdict is reached {#how}

Every entry records how its license verdict was reached, in `audit.method`:

| Method | Meaning |
| --- | --- |
| `tag` | The publisher's own license tag is on the table. No person read it. The page says "license as declared by the publisher". |
| `text-hash` | The license text has the same sha256 as a text a person already read. |
| `inherited` | The base model's verdict is stricter, so it applies. |
| `reviewed` | A person read this repo's license and recorded the result. |
| `queue` | No person has read this license yet. Listed as a link only: "License not reviewed. Read it on the publisher's page." Repos that ship the same text are decided together later. |

The strictest verdict along base model, fine-tune and quantization wins. A quantization of a refused base model is refused, whatever its own tag says.

## Custom licenses {#custom}

A custom or community license (for example a model-specific license) is allowed only after:

1. A person reads it once and records the result, with the sha256 of the text or the declared license name.
2. The model page shows the license and its terms before download.
3. The license lets a third party redistribute with no acceptance gate and no territory limit. If it does not, we link to the source only.

Hosted with terms shown on the entry: OpenMDW 1.1 (keep the agreement and copyright notices with the files), LFM 1.0 (commercial use only for organisations under US$10M annual revenue) and OpenRAIL++-M (the use restrictions in Attachment A pass on to you). The license file is one of the manifest's files when the repo has one.

The manifest records `redistribution` as `yes`, `no` or `click-through`, with the hash of the license text.

## Non-commercial and restricted licenses {#non-commercial}

A non-commercial license means link only: the page links to the source, and Freeweights never hosts a copy. A license that limits where it applies (Tencent Hunyuan community, MiniMax-H3) is link only, labelled territory-limited. Llama, Gemma and DINOv3 licenses must be accepted at the source, so they are link only, labelled gated. Other OpenRAIL licenses and GPL, LGPL and AGPL for weights are link only as not reviewed.

Always read the license yourself before you build on a model. The checks here help; they are not legal advice.

## Gated repos {#gated}

A repo behind a login, an access form or an acceptance gate at the source is listed as a link only. We do not copy gated files and we do not bypass a gate. A repo that becomes gated after it was listed becomes link only.

## What we refuse {#refused}

- No license at all.
- A model the content gate holds for a person (a real person's face or voice, fraud or attack tools) is not listed until a person decides.
- Pickle-only weights. See [the inclusion policy](inclusion.md) for the formats we accept.
- Content banned by the content policy, whatever its license.

Every refusal is logged with model, source, license found, date and reason. The summary is on the Wanted page.

## Rules for every listing {#every-listing}

- The license text and a checksum appear with every file.
- A license change at the source is checked on each sync. A change to a license that is off the table makes the model link only, as not reviewed.
