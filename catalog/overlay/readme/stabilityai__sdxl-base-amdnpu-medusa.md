# 🚀 SDXL-Base on AMD NPU

"SDXL is a latent diffusion model for text-to-image synthesis. Compared to previous versions of Stable Diffusion, SDXL leverages a three times larger UNet backbone, achieved by significantly increasing the number of attention blocks and including a second text encoder." ([stabilityai/stable-diffusion-xl-base-1.0](https://hf.co/stabilityai/stable-diffusion-xl-base-1.0))

This version of the model has been optimized to run on AMD NPUs.

For more information, refer to the original model card under [stabilityai/stable-diffusion-xl-base-1.0](https://huggingface.co/stabilityai/stable-diffusion-xl-base-1.0).



> **M1.0 variant:** This repository contains the M1.0-optimized NPU model derived from [amd/sdxl-base-amdnpu](https://huggingface.co/amd/sdxl-base-amdnpu).
