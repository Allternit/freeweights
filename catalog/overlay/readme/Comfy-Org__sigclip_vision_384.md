# SigLIP Vision 384

Repackaged model files for ComfyUI.

Original model repository: https://huggingface.co/google/siglip-so400m-patch14-384

Place the files in the following folders:

```
📂 ComfyUI/
├── 📂 models/
│   ├── 📂 clip_vision/
│   │   └── sigclip_vision_patch14_384.safetensors
```

---
Used in the ComfyUI [Flux Redux Example](https://comfyanonymous.github.io/ComfyUI_examples/flux/#redux)
