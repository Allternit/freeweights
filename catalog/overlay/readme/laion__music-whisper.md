# Music Whisper (Whisper Small Fine-tune)

This is a fine-tuned version of [OpenAI Whisper Small](https://huggingface.co/openai/whisper-small) specifically trained for **Music Captioning**. Its mean-pooled encoder state also serves as the 768-d audio fingerprint of [LAION-Tunes](https://huggingface.co/datasets/laion/laion-tunes).

Companion release of the NeurIPS 2026 Evaluations & Datasets Track paper *LAION-Tunes: An Open 1.4M-Track Dataset and Perceptual Benchmark for AI-Generated Music* (Kaczmarczyk, Ahmed, Friedrich, Erickson, Sharoni, Herremans, Schuhmann). Code: [LAION-AI/tunes](https://github.com/LAION-AI/tunes). Demo: [Tunes-Search](https://projects.laion.ai/tunes/search-tunes/).

## Model Details
- **Base Model:** OpenAI Whisper Small
- **Task:** Music Captioning (generating textual descriptions of audio tracks)

## Training

Knowledge distillation from Gemini Flash 2.0. The teacher produced six-field structured captions (Overall Sound, Instrumentation, Tempo, Genre, Mood, Vocals) for 2.91M Suno clips of 3 to 30 s from [laion/captioned-ai-music-snippets](https://huggingface.co/datasets/laion/captioned-ai-music-snippets), cut from [nyuuzyou/suno](https://huggingface.co/datasets/nyuuzyou/suno).

| Setting | Value |
|---|---|
| Base model | `openai/whisper-small` (242M parameters), full fine-tune |
| Objective | Teacher-forced cross-entropy over caption tokens |
| Optimizer | AdamW, lr 1e-5, 500 warmup steps, cosine decay |
| Hardware | 8x A100, DDP |
| Effective batch size | 256 (16 per GPU x 8 GPUs x 2 gradient-accumulation steps) |
| Released checkpoint | Training step 27,218 (validation loss 1.34), more than one pass over the 2.91M clips |
| Checkpoints | Every 5,000 steps, evaluated on a held-out 200-clip set |
| Target length | Captions truncated to Whisper's 448-token limit |
| Inference | `max_new_tokens=440` |
