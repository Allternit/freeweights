## Conversion notice

LM Studio converted the original model weights to GGUF and quantized them with `llama.cpp` b10287. These files were changed from the source model weights in format and, for the quantized variants, numerical precision.

This repository includes the following quantizations:

- `Q4_K_M`
- `Q6_K`
- `Q8_0`
