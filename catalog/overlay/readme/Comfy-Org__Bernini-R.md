# Bernini-R

Repackaged model files for ComfyUI.

Original model repository: https://huggingface.co/ByteDance/Bernini-R

Place the files in the following folders:

```
📂 ComfyUI/
├── 📂 models/
│   ├── 📂 diffusion_models/
│   │   ├── wan2.1_bernini_1.3B_fp16.safetensors
│   │   ├── wan2.2_bernini_r_high_noise_fp16.safetensors
│   │   ├── wan2.2_bernini_r_high_noise_fp8_scaled.safetensors
│   │   ├── wan2.2_bernini_r_high_noise_int8_convrot.safetensors
│   │   ├── wan2.2_bernini_r_high_noise_mxfp8.safetensors
│   │   ├── wan2.2_bernini_r_low_noise_fp16.safetensors
│   │   ├── wan2.2_bernini_r_low_noise_fp8_scaled.safetensors
│   │   ├── wan2.2_bernini_r_low_noise_int8_convrot.safetensors
│   │   └── wan2.2_bernini_r_low_noise_mxfp8.safetensors
```
