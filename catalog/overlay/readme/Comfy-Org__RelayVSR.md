# RelayVSR

Repackaged model files for ComfyUI.

Original model repository: https://huggingface.co/kopper/RelayVSR

Place the files in the following folders:

```
📂 ComfyUI/
├── 📂 models/
│   ├── 📂 diffusion_models/
│   │   ├── relayvsr_x4_int8_convrot.safetensors
│   │   └── relayvsr_x2_lightx2v_int8_convrot.safetensors
│   ├── 📂 vae/
│   │   ├── relayvsr_flash_vae_x4_fp32.safetensors
│   │   └── relayvsr_flash_vae_x2_fp32.safetensors
```
