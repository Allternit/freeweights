## Technical Details

Supports native context length of 8192, with rope scaling available.

INTELLECT-1 is a first-of-its-kind model that was trained on 14 distributed nodes across 3 continues from 30 independent community contributors. It is trained from scratch, it is not a fine tune.

The training code and data is entirely available and open.

For more details, check out their technical paper [here](https://github.com/PrimeIntellect-ai/prime).
