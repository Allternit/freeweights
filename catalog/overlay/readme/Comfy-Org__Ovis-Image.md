# Ovis-Image

Repackaged model files for ComfyUI.

Original model repository: https://huggingface.co/ATH-MaaS/Ovis-Image-7B

Place the files in the following folders:

```
📂 ComfyUI/
├── 📂 models/
│   ├── 📂 diffusion_models/
│   │   └── ovis_image_bf16.safetensors
│   ├── 📂 text_encoders/
│   │   └── ovis_2.5.safetensors
```
