# lotus

Repackaged model files for ComfyUI.

Original model repository: https://huggingface.co/jingheya/lotus-depth-d-v1-1

Place the files in the following folders:

```
📂 ComfyUI/
├── 📂 models/
│   ├── 📂 diffusion_models/
│   │   └── lotus-depth-d-v1-1.safetensors
```
