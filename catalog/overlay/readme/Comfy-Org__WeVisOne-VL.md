# WeVisOne-VL

Repackaged model files for ComfyUI.

Original model repository: https://huggingface.co/tencent/WeVisOne-VL-4B

Place the files in the following folders:

```
📂 ComfyUI/
├── 📂 models/
│   ├── 📂 text_encoders/
│   │   ├── wevisone_vl_4b_bf16.safetensors
│   │   └── wevisone_vl_4b_int8_convrot.safetensors
│   │   ├── wevisone_vl_2b_bf16.safetensors
│   │   └── wevisone_vl_2b_int8_convrot.safetensors
```
