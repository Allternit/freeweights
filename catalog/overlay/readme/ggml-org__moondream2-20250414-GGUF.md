This repo contains the llama.cpp compatible GGUFs of vikhyatk/moondream2: https://huggingface.co/vikhyatk/moondream2.

The GGUFs hosted in the original repo is missing the `tokenizer.chat_template` field, thanks to [@Hahasb](https://huggingface.co/Hahasb/moondream2-20250414-GGUF) for adding the `vicuna` template.

For further discussion, please refer to the PR: https://github.com/ggml-org/llama.cpp/pull/13745
