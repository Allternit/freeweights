## Technical Details

Supports a context length of 128k tokens

Fine-tuned for improved reasoning and instruction-following capabilities

Supports structured reasoning through <think></think> and <response></response> tags

Supports English, German, Spanish, French, Japanese, Portuguese, Arabic, Czech, Italian, Korean, Dutch, and Chinese

Capable of thinking, classification, extraction, coding (including FIM), function calling, and long context tasks such as summarization, RAG, and long document Q/A
