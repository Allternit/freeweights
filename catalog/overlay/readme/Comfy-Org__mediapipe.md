# MediaPipe

Repackaged model files for ComfyUI.

Original model repository: https://github.com/google-ai-edge/mediapipe

Place the files in the following folders:

```
📂 ComfyUI/
├── 📂 models/
│   ├── 📂 detection/
│   │   └── mediapipe_face_fp32.safetensors
```
