# Chroma1-HD

Repackaged model files for ComfyUI.

Original model repository:
- https://huggingface.co/lodestones/Chroma1-HD
- https://huggingface.co/silveroxides/Chroma1-HD-fp8-scaled

Place the files in the following folders:

```
📂 ComfyUI/
├── 📂 models/
│   ├── 📂 diffusion_models/
│   │   ├── Chroma1-HD-fp8mixed.safetensors
│   │   └── Chroma1-HD.safetensors
```

---

- Chroma1-HD.safetensors by [lodestones](https://huggingface.co/lodestones/Chroma1-HD/resolve/main/Chroma1-HD.safetensors)
- Chroma1-HD-fp8mixed.safetensors by [silveroxides](https://huggingface.co/silveroxides/Chroma1-HD-fp8-scaled)
