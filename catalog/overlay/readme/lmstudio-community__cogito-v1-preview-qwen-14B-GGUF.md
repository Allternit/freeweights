## Technical Details

Supports a max context length of 128k tokens (with ROPE settings).

Hybrid reasoning model trained using Iterated Distillation and Amplification.

Optimized for coding, STEM, instruction following and general helpfulness, and have significantly higher multilingual, coding and tool calling capabilities than similarly sized competition.

Trained in over 30 languages.
