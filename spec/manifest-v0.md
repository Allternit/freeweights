# Freeweights manifest v0

One JSON manifest per model, pinned to one upstream commit. The manifest is the trust root for a model: it names the exact files, their sizes and sha256 hashes, the license, and where the bytes can be fetched. Torrent hashes are only an extra source; they are never the trust root (plan F5).

Schema: `manifest-v0.schema.json`. Samples: `samples/`.

## Fields

| Field | Meaning |
| --- | --- |
| `schema_version` | Integer `0`. |
| `id` | `org/repo`, same as the upstream repo name. |
| `section` | `alt.freeweights.<family>`, for example `alt.freeweights.qwen`. |
| `upstream` | `host`, `repo`, `commit` (40-hex, pinned), `url`. |
| `license` | `id` (SPDX or a Freeweights id), `name`, `file_path` (license text in the repo), `file_sha256`, `redistribution` (`yes`, `no`, `click-through`). |
| `files` | One entry per file: `path`, `size` (bytes), `sha256` (hex of file contents), `lfs` (true if stored in Git LFS upstream). For non-LFS files the sha256 is computed by us from the bytes at the pinned commit. |
| `sources` | Ordered places to get the bytes. `type` is `hosted` (Freeweights origin or registered mirror), `seeded` (community seeder, magnet), or `source` (upstream at the pinned commit). Each has `url` or `magnet`, `priority` (lower first) and `last_checked` (UTC time or null). |
| `torrent` | Optional. `infohash_v1`, `infohash_v2`, `magnet`, `web_seeds`. Present only when someone holds the bytes (plan F6). |
| `created_at` | UTC time, `YYYY-MM-DDTHH:MM:SSZ`. |
| `generator` | Tool and version that wrote the file. |
| `sample` | Optional boolean, true only for hand-written samples. Real manifests never carry it. |

## Canonical JSON

Signatures cover exact bytes, so the bytes must be stable:

1. UTF-8, no byte order mark.
2. Object keys sorted by Unicode code point, at every level.
3. Indent of 2 spaces, `": "` after keys, `,` at line end; no spaces before a newline (no trailing spaces).
4. Arrays keep their meaning order: `files` sorted by `path`; `sources` sorted by `priority` then `url`/`magnet`.
5. No floating-point numbers; sizes are integers.
6. Strings escaped as in RFC 8259, with non-ASCII written as raw UTF-8 (not `\uXXXX`).
7. One newline at the end of the file, and no other blank lines.

In Python: `json.dumps(obj, sort_keys=True, indent=2, ensure_ascii=False) + "\n"`.

## Signing

Each manifest has a detached minisign signature (Ed25519) next to it: `<manifest>.minisig`, for example `Qwen/Qwen3-Embedding-0.6B.json` and `Qwen/Qwen3-Embedding-0.6B.json.minisig`.

- Signing key id: `2DC28CC7B26A283B` (key `freeweights-v0`, generated 2026-11-14; public key in the repo as `spec/keys/freeweights-v0.pub`, also published at `/docs` and in the README). The v0 secret key has no password and lives at `~/.config/freeweights/minisign.key`, outside the repo; rotate to an offline, password-protected key before Stage 1.
- Public key: `RWQ7KGqyx4zCLXtUFOqvfv8L3g+8fpKJ1FsuxPyOYMF+4KufbUxKq1Oq`
- Signing (maintainers): `minisign -Sm manifest.json -s ~/.config/freeweights/minisign.key` (`scripts/make_manifest.py` does this; CI never holds the key). Manifests generated by the tool are stored as `manifests/<org>__<repo>.json`.

Anyone can verify with stock minisign and no Freeweights software:

```
curl -O https://freeweights.allternit.com/manifests/Qwen/Qwen3-Embedding-0.6B.json
curl -O https://freeweights.allternit.com/manifests/Qwen/Qwen3-Embedding-0.6B.json.minisig
minisign -Vm Qwen3-Embedding-0.6B.json -P <pubkey>
```

A manifest whose signature fails, or whose bytes are not canonical, must be rejected by clients. Key rotation: a new key signs a `keys.json` that the old key also signs; both stay listed for 90 days.

## Verifying a download

1. Verify the manifest signature.
2. Download each file from any source.
3. Check `size` and `sha256` for every file. Any mismatch means discard and try the next source.

## Allowed formats

Model repos must hold safetensors, GGUF, MLX or ONNX weights. ONNX is data-only and allowed (decision 2026-11-14). Pickle-only repos (`.bin`, `.pt`, `.pkl`, `.ckpt` with no safe weights) are refused by `scripts/make_manifest.py` with a logged reason. The same list is the `formats` enum in `catalog-schema.json`.

## Source URLs

A `source` or `hosted` entry's `url` is a base URL: the file URL is `url` + the percent-encoded `path`. For upstream sources the base is `https://huggingface.co/<repo>/resolve/<commit>/`.
